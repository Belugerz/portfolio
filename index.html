Projects

Explainable Deepfake Face Detection: Comparative Analysis of Grad-CAM and LIME Across CNN-based Models on FaceForensics++ Benchmark
Research comparing Grad-CAM and LIME explanations across XceptionNet, EfficientNet-B0, and ResNet50 for deepfake detection on FaceForensics++. Found that the two XAI methods agree only weakly, and that their agreement differs significantly by architecture (EfficientNet-B0 > ResNet50 > XceptionNet). Built with Python, PyTorch, and LIME, and submitted to ICTIM 2026. (Paper is not published yet)
URL shortener
A URL shortening web app built with Express.js, TypeScript, and SQLite. Generates unique base62-encoded codes for each URL and automatically redirects to the original link when accessed. Implements a REST API with persistent storage and click tracking for every shortened link.
Pastebin Clone
Built with Express.js and TypeScript, this app lets users submit text and get a unique shareable link instantly. The backend generates a short code per submission, stores the content, and serves it back when the link is visited. This project strengthened core backend skills like routing and ID generation, building on an earlier URL shortener project.
Sustainable Energy Analysis
A data mining project analyzing global sustainable energy trends across 130+ countries from 2000 to 2020, exploring relationships between GDP, electricity access, renewable share, and energy intensity. The project uncovered key insights such as the inverse relationship between electricity access and renewable share, and how all income groups improved energy efficiency over two decades. Built using Python with exploratory data analysis, statistical correlation, and multi-variable visualization techniques.
